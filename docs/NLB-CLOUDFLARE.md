# NLB و Cloudflare نارنجی

`NLB` الان **VLESS + REALITY** روی `b.sadaftech.ir` → IP هلند (خاکستری) است.

**فقط زدن نارنجی روی همان رکورد REALITY معمولاً کار نمی‌کند:** کلادفلر TLS را خودش تمام می‌کند و REALITY به Origin خام نیاز دارد.

برای مسیر پشت CF:

1. یک ساب‌دامنه جدا (مثلاً `c.sadaftech.ir`) با **Proxied (orange)**.
2. روی Exit یک inbound از نوع **CDN-XHTTP** (یا XHTTP پشت پورت سازگار با CF مثل 2053).
3. Host سوم در پاسارگارد با همان دامنه.

`b.sadaftech.ir` را به‌عنوان **پشتیبان مستقیم خاکستری** (وقتی WW قطع است) نگه دار؛ برای «پنهان‌سازی IP» از `a` + تانل ایران استفاده کن.
